# Network Diagram

This folder contains the network topology diagram for the Week 3 Advanced Cybersecurity Practical.

## Lab Environment

The authorized lab environment includes:

- Kali Linux – Security Testing Machine
- Windows VM – Authorized Target Machine
- VirtualBox – Virtualization Platform

## Network Components

- Kali Linux IP Address
- Target VM IP Address
- Subnet Information
- Default Gateway
- Network Connection

The network diagram will visually represent the communication between the authorized lab machines.
