# Week 3 – Advanced Cybersecurity Practical

## Introduction
This project focuses on performing a practical network security assessment in an authorized lab environment. The assessment includes network discovery, Nmap scanning, service detection, Wireshark traffic analysis, vulnerability assessment, and security hardening.

## Objectives
- Perform network discovery and host identification.
- Identify open ports and running services using Nmap.
- Perform service and version detection.
- Analyze network traffic using Wireshark.
- Understand TCP, UDP, DNS, ICMP, and ARP traffic.
- Identify potential security risks and vulnerabilities.
- Perform security hardening and before/after testing.

## Tools Used
- Kali Linux
- Nmap
- Wireshark
- VirtualBox
- GitHub

## Tasks Completed
- Network Discovery & Basic Nmap Scanning
- Advanced Nmap Security Assessment
- Wireshark Network Traffic Capture
- Nmap + Wireshark Investigation
- Advanced Network Traffic Investigation
- Vulnerability Assessment
- Security Hardening & Before/After Testing
- Final Mini Security Assessment

## Learning Outcomes
- Gained practical knowledge of network discovery and security scanning.
- Learned to identify open ports, services, and service versions.
- Developed skills in Wireshark packet capture and traffic analysis.
- Improved understanding of TCP, UDP, DNS, ICMP, and ARP protocols.
- Learned basic vulnerability assessment and security hardening techniques.

## Conclusion
This project provided hands-on experience in network security assessment using Nmap and Wireshark. The practical activities improved understanding of network scanning, traffic analysis, vulnerability identification, and security hardening. Overall, the project strengthened practical cybersecurity skills and knowledge of real-world network security assessment techniques.
